# Generative AI Projects

This repository contains **Generative AI projects developed by Final Year Computer Science and Engineering students** as part of their practical learning and project-based activities.

The purpose of this repository is to encourage students to identify a problem of their interest and develop a **small, focused, and functional solution using Generative AI technologies**.

## Objectives

* To provide hands-on experience with Generative AI technologies.
* To encourage students to identify and address practical problems.
* To develop problem-solving and implementation skills.
* To familiarize students with current Generative AI tools, models, and frameworks.
* To encourage independent thinking, experimentation, and innovation.

## Project Guidelines

* Students may select a **project idea of their own choice**.
* The selected problem should be clearly defined and relevant.
* The project should make meaningful use of **Generative AI**.
* Projects should be **small, focused, and manageable** within the given time.
* A large-scale or production-level application is not required.
* The project must have a working implementation that can be demonstrated.
* Students should be able to explain the approach, technologies, and implementation used.

## Team Size

* A project may be completed individually or in a team.
* **Maximum team size: 3 students.**
* Each team member must contribute to the project.
* Individual responsibilities should be clearly defined in the project documentation.

## Rules and Requirements

1. Every project must contain a **working implementation**.
2. **Source code is mandatory.**
3. A **PowerPoint Presentation (PPT) is mandatory** for every project.
4. A `README.md` file must be provided with the project.
5. The project should demonstrate the practical use of Generative AI.
6. Students should develop or meaningfully modify the solution rather than directly copying an existing project.
7. All external resources, including datasets, APIs, models, libraries, and research papers, must be properly acknowledged.
8. Students must maintain originality and appropriate attribution throughout the project.
9. Every team must follow the prescribed repository structure.
10. Students must be prepared to explain and demonstrate their project.

## Evaluation Considerations

Projects may be considered based on:

* Clarity of the problem statement
* Relevance of the proposed solution
* Appropriate use of Generative AI
* Technical implementation
* Working of the prototype
* Quality of results
* Individual contribution
* Documentation
* Presentation
* Demonstration
* Innovation and creativity

## Important

The **complexity or size of the project is not the primary objective**.

Students are expected to develop a **well-defined, functional, and understandable Generative AI solution** within the available time.

> **Identify a Problem → Build a Solution → Apply Generative AI → Demonstrate the Result**
