# CivicLens AI Demonstration

## Demo Sequence

1. Open the Home page.
2. Open Scheme Explorer and search for a scholarship.
3. Use Guided Discovery with education and category preferences.
4. Open AI Assistant and ask a scheme-related question.
5. Open Chat with PDF.
6. Upload a text PDF or scanned EWS/hostel/income certificate.
7. Review the OCR/document overview and ask a question.
8. Show the answer and page-specific supporting passages.

## Local URLs

- Frontend: `http://localhost:5173`
- Backend health: `http://localhost:5000/api/health`
- Scheme Explorer: `http://localhost:5173/schemes`
- Chat with PDF: `http://localhost:5173/chat-pdf`

## Responsible Demonstration

Explain that CivicLens AI provides informational guidance only. It does not confirm official eligibility, document authenticity, validity, or application approval. Always verify current requirements with the relevant official portal.
